# 🛡️ Распределенный Multi-Node VPN Кластер (Анти-Блокировка)

Готовое к развертыванию решение для организации устойчивого к блокировкам распределенного VPN-кластера.

Построено на базе связки протоколов **Xray Reality (VLESS TCP 443 + Vision)** и **AmneziaWG**, с централизованной системой генерации подписок под клиентские приложения **HAPP / Hiddify**, динамическим каталогом серверов, сбором метрик в SQLite и персональными веб-кабинетами пользователей.

---

## 🌟 Архитектура системы

```
                               ┌────────────────────────────────────────┐
                               │        Центральный сервер (Nginx)      │
                               │  - Раздача подписок (HAPP / Amnezia)   │
                               │  - API панели управления (Python)      │
                               │  - Защита от зондирования по SNI и IP  │
                               └──────────────────┬─────────────────────┘
                                                  │ Защищенные туннели
                  ┌───────────────────────────────┼───────────────────────────────┐
                  ▼                               ▼                               ▼
       ┌─────────────────────┐         ┌─────────────────────┐         ┌─────────────────────┐
       │   Узел Швейцария    │         │     Узел Эстония    │         │    Узел Германия    │
       │ Xray Reality :443   │         │ Xray Reality :443   │         │ Xray Reality :443   │
       │ AmneziaWG   :443    │         │ AmneziaWG   :443    │         │ AmneziaWG   :443    │
       └─────────────────────┘         └─────────────────────┘         └─────────────────────┘
```

### 1. Маскировка трафика (XTLS Reality)
* Протокол **VLESS + xtls-rprx-vision** на порту 443.
* Эмуляция TLS-рукопожатия реальных сайтов — не требует покупки или выпуска сертификатов на промежуточных узлах.
* Полная устойчивость к активному сканированию и анализу SNI со стороны ТСПУ / РКН.

### 2. Умная маршрутизация (Split-Tunneling для РФ)
* Встроенные правила в единую JSON-подписку HAPP:
  * Трафик к российским сервисам (Госуслуги, банки, Ozon, WB, Yandex, VK и зона `.ru` / `.рф`) идет напрямую без VPN.
  * Трафик к заблокированным и зарубежным ресурсам автоматически туннелируется через выбранный сервер кластера.
  * Защита от утечек DNS (DoH через Cloudflare / Google DNS).

### 3. Динамическое управление серверами (`cluster-node.sh`)
* Единый источник правды: `/etc/vpn-cluster/nodes.json`.
* Добавление или вывод любого сервера из кластера одной командой.
* Автоматическая перегенерация каталога без сброса ключей или обрыва существующих клиентов.

### 4. Персональные веб-порталы
* Легкие и красивые страницы подключения `/nnect/<user>.html` для каждого пользователя.
* Кнопка «Добавить в HAPP» в один клик.
* Защита входа PIN-кодом и тайм-ауты на подбор.

## 📁 Структура репозитория

* `scripts/autoxray.sh` — главный скрипт установки Xray, Nginx, генерации подписок и пользователей.
* `scripts/cluster-node.sh` — утилита CLI для быстрого добавления (`add`), удаления (`rm`) и просмотра (`list`) узлов кластера.
* `panel/panel_core.py` — центральный сервис аналитики и API (фоновый опрос пингов, сбор нагрузки серверов).
* `nginx/nginx-vpn.conf` — обратный прокси с защитой от сканирования IP (сброс 444) и блокировкой прямых TLS-запросов без валидного SNI.
* `config/` — примеры конфигураций узлов (`nodes.example.json`) и переменных окружения.
* `templates/` — шаблон пользовательского веб-кабинета.
* `systemd/` — юнит для автоматического запуска панели как демона.
* `push_to_github.bat` — скрипт в один клик для отправки в ваш репозиторий GitHub.

## 🛠️ Быстрый старт

### 1. Управление серверами кластера
```bash
# Добавить сервер:
sudo ./scripts/cluster-node.sh add de "🇩🇪 Германия" "Dataforest" 198.51.100.30 ""

# Удалить сервер:
sudo ./scripts/cluster-node.sh rm de

# Список всех серверов:
sudo ./scripts/cluster-node.sh list
```

### 2. Управление пользователями
```bash
# Добавить пользователя:
sudo ./scripts/autoxray.sh adduser vpn.example.com alice

# Удалить пользователя:
sudo ./scripts/autoxray.sh deluser vpn.example.com alice

# Синхронизировать всех пользователей с новым списком серверов:
sudo ./scripts/autoxray.sh sync vpn.example.com
```

Каждый пользователь получает:
* Универсальную ссылку на подписку: `https://vpn.example.com/sub/alice.json`
* Персональную страницу со всеми инструкциями: `https://vpn.example.com/nnect/alice.html`

## 🔒 Безопасность
Все боевые IP-адреса, ключи шифрования, токены Amnezia и пароли кластера вынесены в файлы окружения и полностью изолированы от репозитория (файл `.gitignore`).
